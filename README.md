# 밤의 작탁

플레이: https://596428.github.io/mahjong-lab/

리치마작 경험자를 위한 1인 최고점 도전 게임입니다. **패산이 다 떨어질 때까지 최대한 높은 점수를 모으세요.** 화료 한 번으로 끝나지 않고, 남긴 패로 다음 손을 이어갑니다.

## 실행과 배포 파일

이 폴더에서 다음 명령을 실행합니다. Node.js 외에 추가 설치는 필요하지 않습니다.

```powershell
node server.mjs
```

접속: http://localhost:4173

서버는 127.0.0.1에만 바인딩합니다. `dist/`가 정적 웹사이트 전체이고 모든 자산은 상대 경로를 사용합니다. GitHub Pages 등의 정적 호스팅에는 이 디렉터리 내용을 사용할 수 있습니다. 외부 폰트·이미지·API 없이 동작합니다.

## 처음 플레이하기

첫 방문에는 리치마작과 다른 세 가지 핵심 규칙을 안내합니다. 헤더의 `처음 오셨나요?`에서 다시 볼 수 있습니다. `개발 방향`에서는 패산 강화·변경, 특수 효과 조합, 이카사마에 대한 미구현 구상을 확인할 수 있습니다. 장풍·자풍은 도라 패널과 설정에서 東·南·西·北으로 표시합니다.

1. 손패와 공개된 바닥패에서 14장을 클릭하거나 드래그해 중앙에 놓습니다.
2. 역이 있으면 예상 점수를 보고 **화료**합니다. 도라만 있거나 역이 없으면 화료할 수 없습니다.
3. 남은 손패는 유지합니다. 남은 바닥패 중 회수할 패를 고르고 **다음 손으로** 진행합니다.
4. 교환과 추가 공개로 패를 다듬거나, 손패 13장이 텐파이면 리치할 수 있습니다. 바닥패를 포함하려면 패 교환 직후여야 합니다. 리치 버튼에서 후보를 골라도 됩니다.

점수 목표나 점수에 따른 강제 클리어는 없습니다. 패산이 소진돼도 현재 패로 가능한 화료·교환은 계속할 수 있습니다. 화료·추가 공개·교환·리치가 모두 불가능하면 패산이 남아 있어도 도전이 끝납니다. 리치는 손패 텐파이 또는 교환 직후의 바닥패 조합 조건을 만족해야 합니다.

## 패 조작과 비용

- `한 장 더 보기`: 패산 1장 소비. 기본 공개 이후부터 이번 화료 배율이 0.08씩 감소하며, 최저 ×0.40입니다. 버튼에 변경 전후 배율을 표시합니다. 중앙에 조합 중인 패는 그대로 유지합니다.
- `패 교환`: 손패 1~5장을 버리고 바닥패 또는 패산에서 보충합니다. 버릴 손패와 회수할 바닥패를 중앙의 별도 영역에서 확인합니다. 클릭/드래그로 선택하고 중앙 패를 다시 클릭해 취소합니다. 확정할 때만 교환 기회 1회를 사용합니다. 손패를 먼저 보충한 뒤 남은 바닥패를 전부 버리고, 패산에서 기본 공개 장수만큼 새로 받습니다(부족하면 남은 만큼). 재공개는 배율을 더 낮추지 않으며, 기존 배율·추가 공개 한도·회수 한도는 유지합니다. 확정 전 패산 소모 합계를 표시합니다.
- `리치 선언`: 손패 13장 자체가 텐파이면 선언할 수 있습니다. 바닥패를 포함한 텐파이 13장 선택은 **패 교환 직후 기본 바닥패를 재공개한 상태에서만** 가능합니다. 최초 기본 공개는 해당하지 않으며, 한 장 더 공개하면 기회가 닫힙니다. 다시 패 교환을 확정하면 새 기회가 열립니다. 패 선택·순서 변경·힌트 확인은 기회를 닫지 않습니다. 다음 손으로 넘어가면 기회가 초기화됩니다. 중앙에서 직접 선택하거나 리치 버튼에서 후보를 고를 수 있습니다. 대기패를 확인하고 선언하면 선택한 13장을 고정하고 나머지 손패·바닥패를 버립니다. 교환 횟수·회수 한도는 소비하지 않으며 현재 배율을 유지합니다. 패산이 남아 있어야 선언할 수 있고, 이후 화료까지 자동 쯔모기리합니다.
- 마지막에 놓은 패가 기본 화료패입니다. 중앙의 선택 메뉴에서 변경할 수 있습니다. 제출 공간 안에서 드래그해 패 순서를 바꿀 수 있으며, 정렬은 화료패 지정과 점수에 영향을 주지 않습니다. 핑후·암각 판정에 사용하며 실제 마작의 획득 경로를 재현하는 규칙은 아닙니다.

리치 후 첫 4장 이내 화료하면 일발입니다. 선언 당시 공개 배율을 유지하며 리치 쯔모와 뒷도라를 적용합니다. 선언 때 버린 손패·바닥패와 쯔모기리는 계속 표시합니다. 소모 장수에는 화료패도 포함하되 이미 공개했던 바닥패를 중복 계산하지 않습니다. 화료·실패 이후에도 다음 손을 시작할 때까지 내역을 유지합니다.

## 기본 규칙

| 항목 | 기본값 |
| --- | --- |
| 패 | 34종 × 4장, 적도라 없음 |
| 손패 | 최대 13장 |
| 기본 바닥패 공개 | 4장 |
| 한 손 추가 공개 한도 | 8장(기본 4 + 추가 8), 교환 재공개 제외 |
| 도전 전체 교환 기회 | 5회 |
| 교환 1회 버리기 | 1~5장 |
| 한 손의 바닥패 회수 | 최대 4장, 교환 + 화료 후 회수 합계 |
| 비공개 제외 | 6장 |
| 표시패 | 실제 패에서 도라·뒷도라 각 1장 별도 제외 |
| 장풍·자풍 | 동·동 |

설정에서 규칙을 변경할 수 있습니다. 새 손이 시작되면 공개 수·회수 한도·배율은 초기화되지만 교환 횟수는 회복되지 않습니다. 표시패는 도전 내내 고정입니다. 뒷도라는 첫 리치 화료에서 공개하며, 뒷도라 가산은 리치 화료에만 적용합니다.

조건을 우회하는 비상 리치는 제공하지 않습니다. 후보 창에는 현재 조건에서 가능한 일부 후보만 표시하며, 원하는 텐파이 13장을 중앙에서 직접 선택할 수 있습니다. 대기패가 실제 패산에 남았는지는 확인하지 않습니다.

## 전용 점수표

높은 판수일수록 높은 점수 구간을 적용합니다. 실제 리치마작의 부수·친/자 계산은 사용하지 않습니다. 역 판수와 도라를 합산한 뒤 아래 점수를 적용하고 공개 배율을 곱합니다.

| 판수 | 기본 점수 |
| --- | ---: |
| 1 / 2 / 3 / 4 / 5 | 100 / 200 / 400 / 800 / 1,600 |
| 6~7 | 2,400 |
| 8~10 | 3,200 |
| 11~12 | 4,800 |
| 13 이상 | 6,400 |
| 역만 | 1개당 6,400 |

획득 점수 = 기본 점수 × 공개 배율, 소수점 버림. 같은 구간의 판수는 같은 기본 점수를 받습니다. 독립 역만은 중첩하되 단기·순정 등의 더블 역만 변형은 적용하지 않습니다.

일반 화료는 문전으로 취급하되 쯔모 역을 주지 않고, 화료패로 완성한 각자는 암각으로 세지 않습니다. 리치는 문전 쯔모입니다. 여러 분해가 가능하면 가장 높은 점수 판정을 적용합니다. 울기·깡·상대 론이 없으며 관련 역, 천화·지화·인화, 유국만관과 로컬 역은 제외합니다. 지원 역 목록은 `게임 방법`에서 확인하세요.

## 최고 기록과 저장

- 도전 종료 시 이 브라우저에 최고 기록을 저장합니다.
- 교환 직후로 제한한 바닥패 리치 규칙 적용 전 기록과는 분리합니다. 이전 기록 데이터는 삭제하지 않습니다.
- 동일한 규칙 설정끼리 비교하며 시드가 달라도 비교합니다. 다른 규칙은 별도 기록입니다.
- 연습 배치는 최고 기록에 반영하지 않습니다.
- 진행 중 새 도전을 시작하면 확인창을 표시합니다. 중도 초기화한 점수는 최고 기록에 저장하지 않습니다.
- 페이지를 열거나 새로고침하면 새로운 무작위 시드로 시작하며 현재 진행은 초기화됩니다. 규칙 설정·첫 방문 안내 여부·최고 기록은 브라우저에 저장합니다. 저장된 시드는 첫 실행에 재사용하지 않습니다. 설정에서 시드를 직접 입력하거나 종료 후 `같은 패산으로 다시`를 선택하면 동일한 패산을 재현할 수 있습니다.
- 설정의 `플레이 기록 저장`은 시드, 설정, 행동, 점수 판정을 JSON으로 내보냅니다. 비공개 패 목록은 도전 종료 후에만 포함합니다. 자동 리플레이 불러오기는 없습니다.

## 연습과 검증

`설정 → 연습용 배치`에 화료, 역 없는 패, 리치·일발, 교환 직후 리치 배치(교환 직후 상태를 재현)가 있습니다. 연습용 패산의 이후 순서는 규칙 확인용이며 밸런스 측정에 사용하지 마세요.

```powershell
npm.cmd test
```

자동 테스트 40개: 역과 화료패 판정, 복합 역만, 도라, 무역 화료 거부, 점수 상한 없는 진행, 리치·일발·바닥패 리치, 버림패 이력, 물리 패 보존, 최고 기록의 저장·격리 등을 확인합니다. 120개 시드의 전체 도전 시뮬레이션과 300개 풀의 형태 탐색 대조 검사를 포함합니다.

데스크톱 브라우저에서 첫 안내, 점수와 비용 표시, 화료, 화료패 변경, 무역 화료 차단, 중앙 조합을 유지한 추가 공개, 제출 패 순서 드래그, 배율을 유지하는 교환 후 바닥패 재공개, 패 회수, 바닥패 리치 후보 선택·확정·버림패 이력 및 추가 공개 후 차단, 연습 모드와 설정 흐름을 확인했습니다. 모바일 실기기 검증은 하지 않았습니다.

## 구성

- `dist/rules.js`: 화료형·대기·역·점수 판정
- `dist/game.js`: 패산·행동·단계·시드·기록
- `dist/app.js`: 플레이 화면·설정·첫 안내·클릭/드래그
- `dist/tile-art.js`: 직접 제작한 SVG 마작 패 도안
- `dist/records.js`: 규칙별 로컬 최고 기록
- `dist/style.css`, `dist/player.css`: 작탁과 플레이어 화면
- `tests/`: 자동 테스트

이 버전은 기본 플레이를 공개해 피드백을 받을 수 있게 다듬은 버전입니다. 조커·상점·패산 강화·캐릭터·보스는 포함하지 않습니다. 점수표와 난이도 수치는 아직 플레이 결과를 보며 조정할 수 있습니다.
